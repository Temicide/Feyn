# Seed one demo course from the original lesson

A fresh database contains one course built from the original cart-speed lesson. The first email in `TEACHER_EMAILS` teaches it, and it has a fixed join code to give to judges. Cart-speed is stored as an ordinary posted assignment in that course, and the hardcoded lesson module is removed, so assignments exist in only one way.

The authored classmates Maya, Noah, Eli and June are enrolled only in the demo course and remain labelled as examples. A course a teacher creates starts with no example students. The sample walkthrough stays available on every assignment, as a separate learner for each student and course, and still cannot grant a real student's completion.

The user will create further courses through the website after the build. Seeding more subjects was rejected so that every other course in the demo is one that was actually created through the app.

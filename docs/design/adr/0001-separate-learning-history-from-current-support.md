# Separate learning history from current support

A student may resolve a misunderstanding after an earlier unsuccessful explanation. Keep the history of attempts, but base current support flags and class recap counts on the latest evidence for each concept. Persistent gaps after a review-and-retry opportunity can prompt teacher review; newer evidence that resolves a gap removes it from the active queue without deleting its history.

Permanent failure flags would send teachers toward problems students have already resolved. Counting failed attempts would also let one learner's retries inflate a class-wide problem. The agreed model counts each learner once per concept, shows missing evidence separately, and leaves final assessment judgment with the teacher.

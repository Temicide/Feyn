# Separate task completion from follow-up results

The main task is explaining the assigned topic to a novice character. The user chose to allow completion when that explanation meets its criteria, even if a diagnostic follow-up is wrong. Store and present the explanation result and each follow-up result separately, with the human teacher retaining final judgment.

Requiring every follow-up to be correct would make a diagnostic question an additional completion gate. The chosen trade-off preserves optional practice and shows the teacher where application remains difficult. Completion therefore does not certify complete mastery. A wrong follow-up remains in history without a penalty or an automatic help flag merely because the student did not retry.

Once earned, completion persists during optional retries. A weaker later response updates the teacher's diagnostic evidence without automatically revoking earlier credit. Mixed-result endings acknowledge the completed explanation and the unresolved question separately, so the scene does not claim complete mastery.
